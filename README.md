# GyroPad

GyroPad is a companion app that allows you to use your phone as a controller for your PC.

## Downloads

You can download the latest version of GyroPad for your device from the [Release](./Release) folder:

- **Android**: Download and install [GyroPad-Android.apk](./Release/GyroPad-Android.apk) on your phone.
- **Windows PC**: Download and run [GyroPadHost-Windows.exe](./Release/GyroPadHost-Windows.exe) on your laptop or PC.

## Setup Instructions

1. Run `GyroPadHost-Windows.exe` on your PC.
2. Install and open the GyroPad app on your Android phone.
3. Connect both devices to the same network and pair them.
