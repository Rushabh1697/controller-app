PS5 DualSense Controller — Complete Button & Function Reference
Reference specification for the Gyropad virtual-controller project
This document covers the standard Sony DualSense wireless controller (not DualSense Edge). It lists the physical controls, system-level functions, common gameplay roles, and hardware features that a virtual controller such as Gyropad may need to reproduce.
1. Important distinction: standard vs. game-specific functions
The DualSense has a defined set of physical inputs, but the exact gameplay action of most inputs is decided by the game. For example, R2 is commonly accelerate/fire, but a particular game can map it to another action. Therefore, Gyropad should expose the physical input rather than hard-code one game action.
PS5 system functions below are based on PlayStation documentation. Features such as haptic feedback, adaptive triggers, motion controls, touch input, and microphone behavior can depend on the game, device, connection method, and software support.

3. Shoulder and trigger controls
L1 / R1
These are digital shoulder buttons. They report pressed/released states rather than a continuous analog position. Their actual gameplay action is game-defined.
L2 / R2
These are analog triggers and are also DualSense adaptive triggers. A game can read partial trigger travel as an analog value and, on supported software, apply variable resistance/tension.
Adaptive-trigger examples
PlayStation describes effects such as a bowstring becoming harder to pull or a car brake producing changing resistance. For Gyropad, this means trigger input and trigger-feedback output should be treated as separate concepts.
4. Analog sticks and stick-clicks
Each stick provides two analog axes. Conceptually, the virtual controller should expose LX/LY for the left stick and RX/RY for the right stick, normally with a centered/resting position. L3 and R3 are separate digital click inputs.
Recommended Gyropad representation:
LX: left-stick horizontal
LY: left-stick vertical
RX: right-stick horizontal
RY: right-stick vertical
L3: left-stick click
R3: right-stick click
5. D-pad
The D-pad has four digital directions: Up, Down, Left, and Right. Games may treat them independently, and some systems/games can react to combinations such as Up+Right.
6. Face/action buttons
Cross (×)
PS5 system navigation: select the highlighted item. In games: action is game-defined.
Circle (○)
Often acts as Back/Cancel in PlayStation UI; in games: action is game-defined.
Triangle (△)
In PS5 menus, commonly performs a context-sensitive action; in games: action is game-defined.
Square (□)
In PS5 menus and games, function is context-dependent; games commonly use it for an action/interact/attack-type command.
7. Create and Options
Create button
The Create button opens the PS5 Create menu and provides screenshot/video-capture functions. Its exact available options can depend on the current context.
Options button
The Options button opens the Options menu in supported contexts. In games it is commonly used for pause/settings/in-game menus, but the game decides the exact behavior.
8. PS button
Pressing the PS button displays the PS5 Control Centre. The Control Centre provides quick access to system features such as Home, Switcher, Notifications, Game Base, Music, Sound, Mic, Accessories, Profile, and Power, depending on context.
For a virtual-controller implementation, PS should be represented as a distinct system button rather than being treated as an ordinary game button.
9. Touchpad
The DualSense touchpad is both a touch surface and a clickable button. Supported games can use touch position, gestures such as swipes, and touchpad clicking. The exact gesture/action mapping is game-specific.
Touch position: X/Y coordinates across the touch surface.
Touch contact: whether a finger is currently touching.
Touchpad click: a separate digital press.
Swipe/gesture: derived from touch movement; game-specific.
10. Motion / gyro controls
The DualSense includes motion controls. Supported games can use controller movement as an input. For Gyropad, this is especially important: the phone's gyroscope/IMU can be translated into virtual controller motion rather than replacing the normal controller buttons.
Useful virtual-controller motion concepts include orientation/rotation, angular movement, and filtering or sensitivity. The exact sensor-to-stick mapping should be configurable.
11. Haptic feedback
DualSense uses haptic feedback actuators instead of traditional rumble motors. Supported games can produce different vibration sensations, including effects associated with environments or weapon recoil.
For Gyropad, haptic output should ideally be modeled as a separate feedback channel. A future phone implementation could translate controller vibration into phone vibration where the mobile OS/device allows it.
12. Built-in microphone, speaker, and mute
The standard DualSense includes a built-in microphone and speaker, plus a headset jack. The Mute button controls the controller microphone. Voice/chat behavior depends on the host system and application.
Built-in microphone: voice input.
Mute button: microphone mute/unmute control.
Controller speaker: supported game/system audio output.
3.5 mm headset jack: wired headset/audio connection.
13. Light bar and player indicators
The controller has a light bar and player indicators. These are output/status features rather than ordinary gameplay buttons. The host can use them to communicate controller/player state.
14. USB-C and connectivity
The DualSense has a USB-C port used for charging and wired connection. PlayStation also supports Bluetooth wireless connection. For the Gyropad project, USB and Bluetooth are transport options; they should be kept separate from the logical controller-input layer.

16. Suggested Gyropad mapping for racing games
A racing profile can keep the complete DualSense-style button layout while using phone motion for steering. One possible profile is only a starting point and should remain user-configurable:
Phone tilt/gyro → left-stick X (steering), with configurable sensitivity, dead zone, center calibration, smoothing, and inversion.
R2 → accelerator.
L2 → brake/reverse.
L1/R1 → configurable racing functions.
D-pad → configurable menus/ERS/radio/etc., depending on the game.
△ ○ × □ → configurable secondary actions.
L3/R3 → configurable stick-click actions.
Options/Create/PS → preserve as dedicated system/controller buttons where the host supports them.
17. Suggested Gyropad mapping for action games such as GoW
For action games, the same physical layout can remain available while the sticks and buttons are mapped to the game's expected controller inputs. The important design principle is that Gyropad should reproduce the controller's input capabilities, not assume one fixed game mapping.
18. Implementation checklist
Digital buttons: 16+ distinct logical inputs.
Two analog sticks with four axes.
Two analog triggers with continuous values.
L3/R3 stick-click inputs.
Touchpad click and touch/gesture layer.
Motion/gyro input layer.
Configurable sensitivity, dead zone, smoothing, inversion, and calibration.
Button remapping/profiles.
Optional haptic feedback output.
Optional adaptive-trigger feedback output.
Microphone/mute support where the target platform permits it.
USB and Bluetooth transport kept separate from the controller-input API.
